基础
链表模拟竖式加法（逐位进位）单链表逆序相加（高精度大整数加法）
单链表结构体节点链表封装类

两个大整数太大无法用普通整型存储，于是把每一位拆成数字存进链表。读入时用头插法逐位插入，输入虽按高位到低位读，链表却变成"个位在前"的顺序；这样从两表头同时往后走就天然对齐数位，模拟手算竖式：本位和 = 两数对应位 + 进位，本位取 sum%10，进位取 sum/10，结果再头插写入新链表，输出即与输入对齐。

单链表就地逆序（链表逆置）

基础
头插法就地逆序（不申请新结点，仅改指针）带头结点单链表的头插法就地逆序
带头结点的单链表尾指针tail
核心思想

读入 n 个整数用「带头结点 + 尾指针 tail」建表，每次尾插都是 O(1)，保持输入顺序。逆序时不另开新链：把原首结点 begin 固定为逆序后的尾结点，不断把 begin 后面的结点摘下、用头插法挂到头结点之后，后摘下的排得越靠前，整体顺序就被翻转。每步只动常数个指针，故为就地 O(n)，最后别忘了把 tail 更新为 begin。

关键代码
void revList() {
    intNode* begin = head->next;
    if (begin == nullptr) return;   // 空表直接返回
    intNode* end = begin->next;
    while (end) {                   // 把end头插到表头之后
        begin->next = end->next;    // 从原位置摘下end
        end->next = head->next;     // end指向当前首结点
        head->next = end;           // end成为新的首结点
        end = begin->next;          // 取begin后的下一个待处理结点
    }
    tail = begin;                   // 原首结点现在是尾结点
}

两个有序顺序表的对称差集

基础
双指针归并扫描 + 同步去重有序顺序表的双指针归并求对称差集（并去重）
顺序表（一维数组）
核心思想

对称差集是只在 A 或只在 B、但不同时出现的元素。两表都已按非递减排好，用双指针 i、j 同时从前往后扫描比较 A[i] 与 B[j]：相等是交集，两边等于该值的重复项一并跳过且不入结果；A[i] 小则只在 A，入结果并跳过 A 中相同值；A[i] 大则对称处理 B。某表扫完后，另一表的剩余元素只属于自己，去重后直接加入。一遍线性扫描即可，无需再排序或查找。

关键代码
while (i < n && j < m) {
    if (A[i] == B[j]) {              // 交集，两边都跳过，不入结果
        int x = A[i];
        while (i < n && A[i] == x) i++;
        while (j < m && B[j] == x) j++;
    } else if (A[i] < B[j]) {        // 只在A中
        int x = A[i]; C[cSize++] = x;
        while (i < n && A[i] == x) i++;
    } else {                         // 只在B中
        int x = B[j]; C[cSize++] = x;
        while (j < m && B[j] == x) j++;
    }
}

寻找右侧第一个更高的元素（下一个更大元素的下标）

进阶
单调栈（从右向左扫描）单调栈求右侧第一个严格更大元素的下标
顺序栈（数组模拟）顺序表
核心思想

为每个位置 i 求右边第一个严格大于 h[i] 的元素下标（1 基，没有则为 0）。朴素逐个向右扫是 O(n²) 会超时。用单调栈从右往左扫描：栈里存当前位置右侧、从栈顶到栈底高度严格递增的候选下标。处理 i 时先弹掉栈顶所有高度 ≤ h[i] 的元素（它们既不更高又被 h[i] 挡住，对更左的位置也没用），弹完后栈顶即答案，再把 i 压栈供更左侧使用。每个下标至多进出栈各一次，故为线性。

关键代码
int top = 0;
for (int i = n; i >= 1; i--) {
    while (top > 0 && h[st[top]] <= h[i]) top--; // 弹掉不高于 h[i] 的候选
    ans[i] = (top == 0) ? 0 : st[top];           // 栈顶即右侧第一个更高者下标
    st[++top] = i;                               // 当前下标入栈
}

二叉树中两个结点的最近公共祖先(LCA)

基础
父指针上行 + 路径标记法求LCA利用父指针求最近公共祖先LCA
父指针数组(parent)孩子表示的二叉树布尔标记数组(on_path)
核心思想

不显式建树，而是把"孩子关系"反向记成父指针数组 parent，使任一结点都能沿 parent 上行到根。先从 x 上行到根，把沿途结点全部标记到 on_path；再让 y 上行，遇到的第一个被标记结点就是两条到根路径的最早交汇点，即最近公共祖先（LCA）。这样把 LCA 转化为"两条到根路径求第一个公共点"，无需求深度、无需递归。

关键代码
// 1) 孩子关系反存为父指针

    cin >> a >> b;

    if (b) parent[b] = i;
}
// 2) 标记 x 到根的整条路径
for (int p = x; p; p = parent[p])
    on_path[p] = true;
// 3) y 向上走，第一个落在 x 路径上的点即 LCA
int ans = y;
while (!on_path[ans]) ans = parent[ans];
cout << ans << endl;

二叉树原地展开为先序链表

进阶

二叉树（数组静态存储）结构体数组模拟指针单链表（复用right指针）
核心思想

把二叉树原地改成一条只沿 right 走的链表，顺序恰为先序（根-左-右），且不用栈或递归只花 O(1) 额外空间。对每个有左子树的结点 cur，找到其左子树的最右结点 pre（左子树先序的最后一个），把 cur 原来的右子树挂到 pre.right，再把整棵左子树搬到 cur 的右边并置空 cur 的左指针，然后沿 right 继续。

关键代码
while (cur != 0) {

        while (tree[pre].right != 0)   // 找左子树最右结点

        tree[pre].right = tree[cur].right; // 原右子树挂到前驱后
        tree[cur].right = tree[cur].left;  // 左子树搬到右边
        tree[cur].left  = 0;               // 置空左指针
    }
    cur = tree[cur].right;            // 沿右链前进
}

核心思想

这是一棵用结构体数组存的完美二叉树（下标1为根，0表空），要给每个节点填 next，指向同层右邻居、最右节点为0。诀窍是不用队列：边走边用「上一层已经连好的 next」去连下一层——同父的左孩子直接连右孩子，右孩子则跨到 cur.next 的左孩子；每层从最左节点 levelStart 横扫，再 levelStart=left 下降一层。每个节点只访问一次，额外空间 O(1)。

关键代码
int levelStart = root;
while (tree[levelStart].left != 0) {      // 还有下一层
    int cur = levelStart;
    while (cur != 0) {                     // 横向扫当前层
        int l = tree[cur].left, r = tree[cur].right;
        tree[l].next = r;                  // 同父：左->右
        if (tree[cur].next != 0)           // 跨父：右->右邻居的左孩子

        cur = tree[cur].next;              // 沿上层next横向走
    }
    levelStart = tree[levelStart].left;    // 下降一层
}

综合
迭代DFS枚举根到叶路径 + 高精度大数累加根到叶路径枚举与高精度加法

核心思想

一棵二叉树每个结点存一位数字(0-9)，从根到每个叶子拼成一个数，要把所有这样的数相加。做法是用一次 DFS 枚举所有根到叶路径：进结点压入 path，到叶子就把当前路径数字累加进总和，离开时弹出回溯。由于位数可能很长会溢出整型，总和用 vector 低位在前做高精度加法；为防递归爆栈，用显式栈加 state 标记(0 进入/1 回溯)手工模拟递归的进入与返回两个时机。

        addPathToSum(path, sum); // 到叶子：把这条路径数字累加进总和

        if (tree[cur.node].left)  st.push({tree[cur.node].left, 0});
    }
} else {                         // state==1 回溯
    path.pop_back();
}

void siftUp(int i){              // 上浮：比父亲小就换上去
    while(i>1 && heap[i]<heap[i/2]){
        swap(heap[i], heap[i/2]); i/=2;
    }
}
void siftDown(int i){           // 下沉：与较小孩子比较
    int sz=heap.size()-1;
    while(i*2<=sz){
        int c=i*2;
        if(c+1<=sz && heap[c+1]<heap[c]) c++;   // 选较小孩子
        if(heap[i]<=heap[c]) break;
        swap(heap[i],heap[c]); i=c;
    }
}

有向图的连通分量（弱连通分量个数）

基础
并查集（路径压缩 + 按集合大小合并）并查集求无向图连通分量（弱连通）
并查集parent数组setSize数组（按秩/按大小合并）
核心思想

求弱连通分量就是忽略边的方向后，两点是否在同一无向连通块里，本质等价于求无向图的连通分量个数。因此不必真正建图，读入每条有向边 u→v 就把 u、v 两个集合合并；处理完所有边后，统计根节点（findRoot(i)==i）的个数即为答案。自环和重边因合并同根会直接返回，不影响结果。

关键代码
int findRoot(int x) {            // 路径压缩，纯循环
    int root = x;
    while (parent[root] != root) root = parent[root];
    while (parent[x] != x) { int p = parent[x]; parent[x] = root; x = p; }
    return root;
}
void unite(int a, int b) {       // 按集合大小合并
    int ra = findRoot(a), rb = findRoot(b);
    if (ra == rb) return;        // 同集合（重边/已连通）直接返回
    if (setSize[ra] < setSize[rb]) swap(ra, rb);  // 小挂大
    parent[rb] = ra; setSize[ra] += setSize[rb];
}
// 主流程：每条边 if(u!=v) unite(u,v); 最后统计 findRoot(i)==i 的个数

无向图最短路径

基础
BFS广度优先搜索求无权图最短路无权图BFS最短路（链式前向星存图）
链式前向星（数组模拟邻接表）顺序队列（手写IntQueue）距离数组distance[]
核心思想

无权图里每条边长度都看作 1，求 s 到 t 的最短路就是求最少边数。BFS 从起点一层层向外扩展：第 0 层是 s，第 1 层是它的直接邻居……由于按距离从小到大发现节点，某点第一次被访问时一定走的是最少边数，所以第一次碰到 t 得到的 distance 就是答案。用 distance[i]=-1 既表示未访问又当 visited 标记，自环和重边都自动失效。

关键代码
distance[s] = 0;
nodes.push(s);
while (!nodes.empty()) {
    int current = nodes.pop();
    for (int e = graph.firstEdge(current); e != 0; e = graph.nextOf(e)) {
        int nb = graph.targetOf(e);
        if (distance[nb] != -1) continue;          // 已访问跳过(去重/防环)
        distance[nb] = distance[current] + 1;       // 层数+1
        if (nb == t) return distance[nb];           // 第一次到t即最短
        nodes.push(nb);
    }
}
return -1;                                          // s与t不连通

基础
二分查找（lower_bound）二分查找之lower_bound（第一个不小于target的下标）

核心思想

数组 scores 已按非递减顺序存储，要找第一个不小于目标值 x 的下标。每次询问若线性扫描是 O(n)，q 次会超时；利用有序性改用二分查找把单次降到 O(log n)。二分时用变量 answer 记录候选：mid 处值 ≥ target 就先记下并向左收缩找更靠前的位置，否则到右半部分继续。

关键代码
int left = 1, right = scores.size() - 1, answer = 0;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (scores[mid] >= target) {   // mid 可能是答案
        answer = mid;
        right = mid - 1;           // 继续向左找更靠前的
    } else {
        left = mid + 1;            // 答案在右半部分
    }
}
return answer;

两个有序数组中的第 k 小元素

进阶

核心思想

两个分别升序的数组 a、b，求合并后第 k 小元素。利用有序性，每轮比较两侧各自第 half=k/2 个元素，较小一侧的前 half 个必定排在第 k 名之前，整体丢弃并把 k 减去丢弃数量，从而每轮把 k 大约减半，O(log k) 轮即可定位答案，无需真正归并。

关键代码
int half = remain / 2;
int checkA = min(startA + half - 1, n);   // 越界夹到末尾
int checkB = min(startB + half - 1, m);
if (a[checkA] <= b[checkB]) {             // a 侧前缀更小，整体淘汰
    remain -= (checkA - startA + 1);
    startA = checkA + 1;
} else {                                   // b 侧前缀更小，整体淘汰
    remain -= (checkB - startB + 1);
    startB = checkB + 1;
}
// 出口：某侧空 -> 另一侧取第 remain 个；remain==1 -> 取两队首较小者

基础

核心思想

sort(values.begin(), values.end());

    int rank = lower_bound(values.begin(), values.end(), a[i])
               - values.begin() + 1;
    cout << rank;
    if (i + 1 < n) cout << ' ';
}
