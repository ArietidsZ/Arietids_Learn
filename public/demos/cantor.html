不可数集合与 Cantor 定理

不可数不是“数得慢”，而是任何清单都会漏项。若 θ:X→P(X) 试图列出所有子集，对角线集合 Y={x∈X | x∉θ(x)} 会与每一行都不同。

English exam target: Suppose θ:X→P(X) is surjective. Define Y={x∈X | x∉θ(x)}; then for θ(y)=Y, get y∈Y ⇔ y∉Y.

0. 从零开始的语言约定

先对齐这几个词，后面的公式就不会变成符号堆。

核心词汇

  • ≈
    等势 / equinumerous两个集合之间存在双射。意思是“元素数量同阶”，不是集合相等。
  • P
    幂集 / power setP(X) 是 X 的所有子集构成的集合。
  • ↔
    双射 / bijection既单射又满射：不会把两个元素送到同一处，也不会漏掉目标集合中的元素。
  • 2ᴬ
    函数空间记号2ᴬ=(A→{0,1})，即所有从 A 到二元集合的函数。
可数不是“有限”

可数集合可以无限大，只要能排成 a₀,a₁,a₂,... 的清单即可。例如 N 和 Z 都可数。

不可数不是“太多所以懒得数”

不可数的严格意思是：不存在从 N 到它的满射；任何无限清单都会漏项。

子集可以被 0/1 编码

给定 A={a₀,a₁,...}，一个子集等价于一串选择：选中写 1，不选写 0。

证明策略：反证 + 自造反例

先假设清单完整，再沿对角线反着选，造出一个必然漏掉的对象。

五步证明显微镜

下面只拆逻辑动作：假设、构造、命中、矛盾、结论。

1
假设存在双射 θ:X→P(X)双射尤其是满射，所以每个子集都应等于某个 θ(y)。
2
构造 Y={x∈X | x∉θ(x)}只看 x 是否属于自己那一行 θ(x)，然后取相反选择。
3
因为 Y⊆X，所以 Y∈P(X)满射性要求存在某个 y∈X，使得 θ(y)=Y。
4
只问一个问题：y∈Y?若是，则按定义应有 y∉θ(y)=Y；若否，则按定义应有 y∈θ(y)=Y。
5
两边都矛盾，故双射不存在所以 X≈P(X) 不可能，进而 P(N) 不可数。
误区 1：Y 不是“随便找”的集合

Y 逐行计算：第 x 行含 x，Y 就不含；第 x 行不含 x，Y 就含。

误区 2：不是只证明某个 θ 失败

证明从任意 θ 出发，都能造出对应的 Y。所以没有任何双射能成功。

误区 3：连续函数没有所有函数那么多

Rᴿ 允许每个实数点独立取值；连续函数受“极限一致性”约束，被 Q 上取值决定。

1. 幂集就是 0/1 函数空间

这一步把“子集”翻译成“二进制序列”。后面的 2ᴺ 都来自这里。

对每个元素 a∈A，特征函数 χ(a)=1 表示选入子集，χ(a)=0 表示不选。

为什么这个映射是单射？

若两个函数选出的子集相同，则每个 a 的选中状态都相同，所以 f(a)=g(a) 对所有 a 成立。

为什么这个映射是满射？

任给 S⊆A，定义 χ_S(a)=1 当且仅当 a∈S。它正好编码 S。

为什么写成 2^A？

这里的 2 是二元集合 {0,1}；指数 A 表示输入域是 A。

为什么 P(N) 不可数？

Cantor 定理给出 N≉P(N)。若 P(N) 可数，就会有 N→P(N) 的满射，矛盾。

2. 从 P(N) 到函数空间的基数阶梯

重点只看“谁和谁同阶”，不要背散乱等式。

A
P(N)≈2ᴺ自然数子集等价于 0/1 无限序列：第 n 位记录 n 是否被选入。
B
Nᴺ≈2ᴺ下界：0/1 序列也是自然数序列，所以 2ᴺ≤Nᴺ。上界：每个自然数可用二进制序列编码，再用可数多个二进制块拼成一条二进制序列，因此不超过 2ᴺ。
C
R≈2ᴺ可以把 (0,1) 中的实数理解为二进制展开；少数二进制展开不唯一的点不改变基数结论。
D
Rᴿ≈2^(2ᴺ)因为输入集合和输出集合都与 2ᴺ 同阶，所以所有实函数相当于从 2ᴺ 到 2ᴺ 的函数集。
E
C(R,R)≈R连续函数由有理数上的取值决定；有理数可数，所以自由度只有可数多份实数值，最终同阶于 R。

3. 所有实函数 vs 连续实函数

同样是 R→R：任意函数可自由取值；连续函数被 Q 上取值锁定。

任意函数：自由度在每个实数点上

Rᴿ ≈ 2^(2ᴺ)

因为 R≈2ᴺ，所以这是“连续统多个输入，各选一个连续统大小的值”。

1Rᴿ≈(2ᴺ)^(2ᴺ)
2指数律压缩为 2^(N×2ᴺ)
3最终与 2^(2ᴺ) 同阶

连续函数：稠密集决定全局

C(R,R) ≈ R

连续函数在 Q 上确定后，在整个 R 上也唯一确定；而 Q 可数。

1限制到 Q：连续函数注入 R^Q
2R^Q≈Rᴺ≈(2ᴺ)ᴺ≈2ᴺ
3常值函数给出至少 R 个，所以同阶于 R

Cantor diagonal proof

Suppose θ:X→P(X) is surjective. Define Y={x∈X | x∉θ(x)}. Since Y∈P(X), there is y∈X with θ(y)=Y. Then y∈Y iff y∉θ(y)=Y, a contradiction.

Power set as binary functions

Map each subset S⊆A to its characteristic function χ_S:A→{0,1}. This map is injective and surjective, so P(A)≈(A→{0,1})=2ᴬ.

All real functions vs continuous functions

Since R≈2ᴺ, Rᴿ≈(2ᴺ)^(2ᴺ)≈2^(2ᴺ).

A continuous function is determined by its values on Q, so |C(R,R)|≤|R^Q|=|R^N|=|R|. Constant functions give the reverse inequality.

Mastery standard / 透彻掌握

Your English answer must identify the assumed function, construct the diagonal object, use that object's own index, and state exactly why the membership statement contradicts itself.

10-second final check

State the assumed surjection, define the diagonal object, choose the row that should equal it, and write the contradiction. Without those four moves, the proof is not complete.
