Arietids Learn 收集我在交大学习时整理的数学、物理与计算机基础笔记，希望方便后来的同学复习，也方便自己回头查阅。

这里保留了章节详版、速览和一些交互演示。不同课程的整理范围不同，具体章节见各课程目录。

## 阅读与来源

- 详版保留定义、推导、例题与方法；速览用于回顾主要结论。
- 部分笔记按课程讲义和课堂材料整理，原有的来源页码或定位标记随 Markdown 保留。
- 笔记可能有疏漏，也可能与之后的课程安排不同。请结合教材和教师正式说明使用。
- 网站下载包只包含本站笔记和演示，不包含原教材、教师课件或试卷。

## 纠错

[在 GitHub 提出问题](https://github.com/ArietidsZ/Arietids_Learn/issues/new)。请附上页面链接、具体位置，以及建议修改的内容或依据。
